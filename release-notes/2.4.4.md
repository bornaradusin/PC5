PC5 2.4.4 adds a frame rate cap for each game, keeps only a game's saves when you uninstall it, and fixes videos that stayed black or showed enlarged, controllers some games didn't see, and games that stopped because they found no OpenGL.

### Install

- **ProsperoStore**: update PC5 from its page in the store.
- **PC5's own updater**: **Settings › System › Update now**, or **Update now** when PC5 asks as it opens. It downloads only what changed when you have the version before, otherwise the whole app. PC5 restarts by itself when the update is installed.

### New

- **Frame rate cap**: **△ › Graphics › Frame rate cap** holds a game to **30 fps**, or with **Settings › 120 Hz output** on to **40** or **60 fps**, shown evenly on the TV's beat. A game that jumps between fast and slow feels smoother kept at a rate it can always reach. It works with games drawn with Direct3D, Vulkan or OpenGL, and is off while Frame generation is on. See [Frame rate cap](https://github.com/bornaradusin/PC5/wiki/Playing-games#frame-rate-cap).

### Fixed

- **Videos with 48 kHz sound played through Media Foundation** stayed black: the sound lost its timestamps on the way, and the game's player stopped at its first sound. They play now.
- **Films played through DirectShow into part of a texture** were stretched over the whole texture, so only their top-left part showed, enlarged. They are now decoded at the size the game asks for.
- **Unity games set to Xbox controller** whose own input finds controllers through Windows' raw input saw no controller. PC5 now lists the controller there for Unity games, as Windows lists an Xbox controller; other games see no change.
- **Games built with bgfx that draw with OpenGL** stopped at the start ("ChoosePixelFormat failed"), as PC5 had set them up for Direct3D. PC5 now recognises them and gives them OpenGL. A game installed before is checked once at its next start.

### Changed

- **Keep saves keeps only the saves**: uninstalling a game with **Keep saves** now keeps its users' folders and `ProgramData`, its user registry, its options and the files it made in its own folder, and deletes the rest of its Windows (Windows' own files, the rest of its registry, its shader cache) with the game, which takes much less space. **Put them back** makes a new Windows and puts the saves into it, adding the game's own registry keys to the new registry. Saves kept before 2.4.4 are put back the same way.

### Which games run

See the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility), made from players' reports and issues. Got a game running? Use **Report it works** (a game's **△ › Manage**, or PC5's web page), or [add it here](https://github.com/bornaradusin/PC5/discussions/new?category=game-compatibility): the form takes a minute.

### Reporting a problem

Please report problems as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues/new/choose), not in ProsperoStore's comments:
- **A game doesn't run** for a game.
- **A problem with PC5** for PC5 itself.

Attach the game's zip from `/data/prospero-win/logs/`: an `issue-…zip`, or the game's newest `log-…zip` when nothing crashed. The form asks for it, as the cause can't be found without it. **△** on PC5's crash message, or a game's **△ › Manage › Report a problem**, opens the form for you, filled in.

If an update from PC5 fails, the message says why. Turn on **Settings › System › Keep all logs**, try again and attach PC5's own log. See [Logs and debugging](https://github.com/bornaradusin/PC5/wiki/Logs-and-debugging) for what an issue may ask for.

### Not supported

- Games that need a store's launcher or client running (Steam, EA app, Ubisoft Connect, Rockstar Games Launcher).
- Anti-cheat, games that need kernel drivers, and DRM-protected games.
- .NET programs that mix .NET and C++ (C++/CLI).
- 16-bit Windows and DOS programs.
- Recording or saving video from inside a game.
- Frame generation for DirectDraw games and games drawn without 3D, and HDR output.
