PC5 tells you about a new version as it opens, and updates know up front what they download.

### Install

- **ProsperoStore**: update PC5 from its page in the store.
- **PC5's own updater**: **Settings › System › Update now**, or **Update now** when PC5 asks as it opens. It downloads only what changed when you have the version before, otherwise the whole app. PC5 restarts by itself when the update is installed.

### What's new

- **Updates when PC5 opens**: with **Settings › System › Check when PC5 opens** on, PC5 asks GitHub each time you open it, not at most once an hour, and shows a notification when a newer version is out.
- **The right download from the start** (for updates after 1.9.7, which this version's updater makes): PC5 says before it downloads anything whether the update is only what changed (you have the version before) or the whole app (you are more than one version behind), with its size. It no longer downloads the small update first and then the whole app.
- **A quicker last step**, also for updates after 1.9.7: putting the new files in place now writes to the disk only the folders an update changed.
- **Direct3D 12**: Unreal Engine 5 games that load Direct3D 12 themselves are now seen as DirectX 12 and drawn by VKD3D-Proton. Before, PC5 saw them as DirectX 11, and they said DirectX 12 isn't supported. A Direct3D 12 game that asks for graphics memory it can share no longer crashes as it starts: the console can't share it, so it gets ordinary memory.
- Everything in 1.9.6 is unchanged: home screen tiles closing without an error, the Extra large overlay, rumble on the controller's motors, updates that download only what changed, and all since 1.8.2.

### Which games run

See the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility), made from players' reports and issues. Got a game running? [Add it](https://github.com/bornaradusin/PC5/discussions/new?category=game-compatibility): the form takes a minute.

### Reporting a problem

Please report problems as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues/new/choose), not in ProsperoStore's comments: **A game doesn't run** for a game, **A problem with PC5** for PC5 itself. Attach the game's zip from `/data/prospero-win/logs/` (`issue-…zip`, or the game's newest `log-…zip` when nothing crashed): the form asks for it, as the cause can't be found without it. △ on PC5's crash message opens the form for you, filled in. If an update from PC5 fails, the message says why; turn on **Settings › System › Keep all logs**, try again and attach PC5's own log. See [Logs and debugging](https://github.com/bornaradusin/PC5/wiki/Logs-and-debugging) for what an issue may ask for.

### Not supported

Games that need a store's launcher or client running (Steam, EA app, Ubisoft Connect, Rockstar Games Launcher), anti-cheat, and games that need kernel drivers. .NET programs that mix .NET and C++ (C++/CLI). 16-bit Windows and DOS programs. Recording or saving video from inside a game. Frame generation for DirectDraw games, games drawn without 3D, and HDR output. Changing a game's controller mode, resolution or aspect ratio while it runs. DRM protected. PC5 installed as a package (`.pkg`) can't update itself: it updates from a folder only.
