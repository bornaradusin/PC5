PC5 2.1.4 brings back Blade & Sword's picture, shows Unity games' cutscenes, gets Marvel's Spider-Man Remastered and Gears Tactics past their start, and lets AltGr type on AZERTY keyboards.

### Install

- **ProsperoStore**: update PC5 from its page in the store.
- **PC5's own updater**: **Settings › System › Update now**, or **Update now** when PC5 asks as it opens. It downloads only what changed when you have the version before, otherwise the whole app. PC5 restarts by itself when the update is installed.

### Fixed

- **Blade & Sword shows its picture again** (black with sound since 2.0.9). Its opening movie plays in a smaller window of its own, which took the screen from the game. Now only a window at least as large as the game's takes the screen (the menus of Chronicles of the Wolf and Aggelos 2 still do), and a test checks every game this rule was fixed for, so a later change can't break one of them again ([#290](https://github.com/bornaradusin/PC5/issues/290)).
- **Unity games' cutscenes play** instead of staying black with their sound. Unity decodes its movies on a graphics device of their own and hands each picture to the game's through a shared texture, which the PS5's driver couldn't share; the two now share the picture inside the game (Ruined King: A League of Legends Story, [#288](https://github.com/bornaradusin/PC5/issues/288)).
- **Marvel's Spider-Man Remastered, Miles Morales and Ratchet & Clank: Rift Apart** start with DirectX 12 on **Graphics API › Auto**, instead of "DirectX 12 support not detected" ([#275](https://github.com/bornaradusin/PC5/issues/275)).
- **No more "graphics driver too old" message.** AMD-sponsored games ask AMD's driver library for the driver's version, which got no answer on the PS5: Spider-Man warned the driver was below its requirements and The Last of Us Part II logged "Driver Supported: NO". PC5 now answers with a current version (Proton's library) ([#275](https://github.com/bornaradusin/PC5/issues/275), [#276](https://github.com/bornaradusin/PC5/issues/276)).
- **Gears Tactics** gets DirectX 12 instead of crashing after its title screen: its program is in `Binaries\Steam`, not `Binaries\Win64`, so PC5 didn't look for DirectX 12 in it ([#279](https://github.com/bornaradusin/PC5/issues/279)).
- **AltGr on a USB keyboard** types the keys' third characters again, so **AltGr+0** gives **@** on a French (AZERTY) keyboard ([#221](https://github.com/bornaradusin/PC5/issues/221)).
- **The on-screen keyboard** (two fingers on the touchpad) opens over a game again ([#221](https://github.com/bornaradusin/PC5/issues/221)).

### Which games run

See the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility), made from players' reports and issues. Got a game running? [Add it](https://github.com/bornaradusin/PC5/discussions/new?category=game-compatibility): the form takes a minute.

### Reporting a problem

Please report problems as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues/new/choose), not in ProsperoStore's comments:
- **A game doesn't run** for a game.
- **A problem with PC5** for PC5 itself.

Attach the game's zip from `/data/prospero-win/logs/`: an `issue-…zip`, or the game's newest `log-…zip` when nothing crashed. The form asks for it, as the cause can't be found without it. **△** on PC5's crash message, or a game's **△ › Manage › Report a problem**, opens the form for you, filled in.

If an update from PC5 fails, the message says why. Turn on **Settings › System › Keep all logs**, try again and attach PC5's own log. See [Logs and debugging](https://github.com/bornaradusin/PC5/wiki/Logs-and-debugging) for what an issue may ask for.

### Not supported

- Games that need a store's launcher or client running (Steam, EA app, Ubisoft Connect, Rockstar Games Launcher).
- Anti-cheat, games that need kernel drivers, and DRM-protected games.
- .NET programs that mix .NET and C++ (C++/CLI).
- 16-bit Windows and DOS programs.
- Recording or saving video from inside a game.
- Frame generation for DirectDraw games and games drawn without 3D, and HDR output.
- Output above 120 Hz, and variable refresh rate (VRR).
- Changing a game's controller mode, resolution or aspect ratio while it runs.
- Updating a PC5 installed as a package (`.pkg`): it updates from a folder only.
