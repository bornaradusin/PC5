PC5 2.3.1-programs-test2 is the second test version that lets a game start other programs. It is everything in the first test version, plus what's new below.

This is a pre-release for testing. PC5 offers it only when **Settings › Check when PC5 opens** is set to **Test versions too**, and it offers you the next normal release when there is one.

### What's new since the first test version

- **OpenGL for more games.** A game that draws as ordinary Windows programs do now has OpenGL ready in case it asks for it while it runs, as games made with SDL, FNA, MonoGame or Java do. Before, such a game found no OpenGL and closed at once.
- **A game made with FNA, or with MonoGame's OpenGL version,** is now recognised as an OpenGL game when it's installed. A game installed before is put right the next time it starts.
- **Graphics mode Windows only.** Those games now have a **Graphics mode** choice: **Auto** (OpenGL ready) and **Windows only** (without OpenGL, as before). If a game starts or draws worse than before, set it to **Windows only** (△ on the game › Graphics).

### Games that start other programs

Some games start a second program while they run: a setup that installs files the game needs (Visual C++, DirectX, .NET, PhysX), or a built-in web browser's own programs, when the game's menus are web pages. PC5 starts those programs for the game, each as a program of its own, hidden: nothing of them is on the screen, and the game goes on once they're done. PC5 uses elfldr for this, as it already does for its access to `/data`, so keep elfldr loaded.

### Install

With **Test versions too** set, PC5 offers this version the next time it opens. By hand: download `PPSA11018-test.zip` below, unzip it and replace the `PPSA11018` folder on the console with the new one, the way you added PC5 (see [Installing and updating](https://github.com/bornaradusin/PC5/wiki/Installing-and-updating#by-hand)). Your games, saves and settings stay. To go back, set the setting to **On**, or do the same with 2.3.0's zip.

### What to test

- A game that stopped at its setup or its launcher, or one whose issue says it couldn't start another program.
- A game that closed at once looking for OpenGL, and any game that draws as ordinary Windows programs do: does it still work as before?
- Open a game issue as usual, with **test version** at the start of its title, and attach the game's newest log. **Every log helps, even if the game still doesn't work.**
