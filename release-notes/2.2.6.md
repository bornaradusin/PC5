PC5 2.2.6 makes copying games to the console faster, adds a **Report it works** button to PC5's web page, and fixes games that crashed when a movie started, a game that stopped at start, and saves that couldn't be written.

### Install

- **ProsperoStore**: update PC5 from its page in the store.
- **PC5's own updater**: **Settings › System › Update now**, or **Update now** when PC5 asks as it opens. It downloads only what changed when you have the version before, otherwise the whole app. PC5 restarts by itself when the update is installed.

### Faster copying

- **From a USB drive**: installing a game copies it in the background, reading and writing at the same time, and redraws the screen less while it copies.
- **Check copied games**: a new setting, under **Settings › Game maintenance**, for whether PC5 reads a game back after copying it to check every file. **Off** (the default) is the fastest; **Big games only** (games over 20 GB) and **Always** check, which takes about as long again.
- **Over FTP and PC5's web page**: larger network buffers and fewer, larger writes to the disk. FTP takes up to 12 connections at once, and the web page sends several files at once.

Tips: a wired network connection is the fastest; in FileZilla, 4 to 6 simultaneous transfers work well; plug USB drives into a USB 3 port; and a game with thousands of small files copies faster as one zip.

### Report it works

The **Games** list on PC5's web page has a **Report it works** button beside **Report a problem**. It opens the game compatibility form with the game, PC5's version and the game's settings filled in, so adding a game that runs to the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility) takes a few seconds.

### Fixes from your reports

- **Games that crashed as a movie started**: a game that plays its movies in a window of their own, beside the game's, crashed when the movie began, as the console's display had no room for a second picture. The movie's window now gets one of its own that isn't shown.
- **A game that stopped at start looking for its C runtime**: a game that brings its own copy of the C runtime, and asks for it by another of its names, was told it wasn't there and stopped. It is now found.
- **Saves that couldn't be written**: a game that checks whether a file it has just made can be written was told no, and couldn't save. Every file in a game's folders is now the player's to write.
- **OpenGL games that close a window and open another** were refused a picture for the new window. The old window's picture now goes with it.
- **Games that saw too little video memory**: the console's 16 GB of memory read as 0 in one of the places games look, and some games refused to start. It now reads right there too.
- **The GPU's name and ID**: games now see the console's GPU as an AMD GPU they know, not an unknown one, so a game that picks its settings by the GPU finds a match.
- **Games that spread their work over the CPU's cores** now see which core each thread runs on, where every thread said it ran on the first.
- **Visual C++ 2010 to 2013** are recorded as installed, so a game's setup that checks for them doesn't try to install them.
- **Launchers that check how they started a game** can now read the game's command line.

### Which games run

See the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility), made from players' reports and issues. Got a game running? Use **Report it works** on PC5's web page, or [add it here](https://github.com/bornaradusin/PC5/discussions/new?category=game-compatibility): the form takes a minute.

### Reporting a problem

Please report problems as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues/new/choose), not in ProsperoStore's comments:
- **A game doesn't run** for a game.
- **A problem with PC5** for PC5 itself.

Attach the game's zip from `/data/prospero-win/logs/`: an `issue-…zip`, or the game's newest `log-…zip` when nothing crashed. The form asks for it, as the cause can't be found without it. **△** on PC5's crash message, or a game's **△ › Manage › Report a problem**, opens the form for you, filled in.

If an update from PC5 fails, the message says why. Turn on **Settings › System › Keep all logs**, try again and attach PC5's own log. See [Logs and debugging](https://github.com/bornaradusin/PC5/wiki/Logs-and-debugging) for what an issue may ask for.

### Not supported

- Games that need a store's launcher or client running (Steam, EA app, Ubisoft Connect, Rockstar Games Launcher).
- Anti-cheat, games that need kernel drivers, and DRM-protected games.
- .NET programs that mix .NET and C++ (C++/CLI).
- 16-bit Windows and DOS programs.
- Recording or saving video from inside a game.
- Frame generation for DirectDraw games and games drawn without 3D, and HDR output.
