PC5 2.0.4 brings GPU usage on the overlay, an easier way to report a problem, a better web page, and fixes from your reports.

### Install

- **ProsperoStore**: update PC5 from its page in the store.
- **PC5's own updater**: **Settings › System › Update now**, or **Update now** when PC5 asks as it opens. It downloads only what changed when you have the version before, otherwise the whole app. PC5 restarts by itself when the update is installed.

### What's new

- **GPU usage on the overlay**: **Settings › Overlay › GPU usage** shows how busy the console's GPU is.
- **CPU usage is the console's**: the CPU line now shows how busy the console's CPU is with everything it runs, instead of the game's share.
- **The log records the frame rate**: while the overlay is on, the game's log has a line each second with the FPS, the GPU's and the CPU's use and the busiest CPU core's, so a log shows what slows a game down where its frame rate dips.
- **Report a problem, any time**: a game's **△ › Manage › Report a problem** shows a QR code for GitHub's form, filled in from the game's newest log, also after the crash message is gone.
- **Reports fill in more**: the form now also gets what goes wrong, the name of the log to attach and the game's settings (Graphics API, controller, frame generation, memory, CPU sharing).
- **Web page**:
  - **Report a problem** for each game: downloads its newest log and opens GitHub's form, filled in.
  - Each game's settings at a glance, a USB drive tag, and **Find a game** when there are many.
  - **Extra logging (winedebug.txt)** for a game, for when an issue asks for it.
  - The logs show their date, and which ones had a problem.
  - Links to the compatibility list, the wiki and PC5's own issue form.
  - **Settings › Network › Web page**: **△** shows its address as a QR code for your phone.
- **Clearer settings**: plainer descriptions for Graphics API, Frame generation, CPU sharing, Keep all logs and Uninstall, and an empty library says every way to add a game.

### Fixes from your reports

- **Older games that build their shaders at start** (with the compiler they run): the shaders now assemble, so effects, lighting and detailed textures show instead of being left out.
- **A game that writes just past the end of a large block of memory** no longer crashes, as on Windows.
- **Games installed on a USB drive** whose files PC5 closes and opens again (with many files open) could lose them: they are now opened again as the same file, and a failure is logged.
- **DirectDraw games with their own Direct3D 9 renderer** (a `ddraw.dll` wrapper in the game's folder): **△ › Graphics › Graphics API** now changes what draws them.

### Which games run

See the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility), made from players' reports and issues. Got a game running? [Add it](https://github.com/bornaradusin/PC5/discussions/new?category=game-compatibility): the form takes a minute.

### Reporting a problem

Please report problems as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues/new/choose), not in ProsperoStore's comments:
- **A game doesn't run** for a game.
- **A problem with PC5** for PC5 itself.

Attach the game's zip from `/data/prospero-win/logs/`: an `issue-…zip`, or the game's newest `log-…zip` when nothing crashed. The form asks for it, as the cause can't be found without it. **△** on PC5's crash message, or a game's **△ › Manage › Report a problem**, opens the form for you, filled in.

If an update from PC5 fails, the message says why. Turn on **Settings › System › Keep all logs**, try again and attach PC5's own log. See [Logs and debugging](https://github.com/bornaradusin/PC5/wiki/Logs-and-debugging) for what an issue may ask for.

### Not supported

- Games that need a store's launcher or client running (Steam, EA app, Ubisoft Connect, Rockstar Games Launcher).
- Anti-cheat, games that need kernel drivers, and DRM-protected games.
- .NET programs that mix .NET and C++ (C++/CLI).
- 16-bit Windows and DOS programs.
- Recording or saving video from inside a game.
- Frame generation for DirectDraw games and games drawn without 3D, and HDR output.
- Changing a game's controller mode, resolution or aspect ratio while it runs.
- Updating a PC5 installed as a package (`.pkg`): it updates from a folder only.
