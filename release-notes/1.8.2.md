A new look for the library, with the covers standing on a floor that mirrors them; a System page in Settings; more places to find covers, each of which can be turned off; Java games; games started from a batch file run as 32-bit or 64-bit like their program; and a startup sound that follows the console's volume.

### Install

From PC5 1.8.0 or 1.8.1: **Settings › Updates › Update now**, or **Update now** when PC5 asks as it opens. PC5 restarts by itself when the update is installed.

By hand:

1. Download `PPSA11018.zip` and unzip it.
2. Replace the `PPSA11018` folder on the console with the new one, the way you add homebrew. Your games, saves and settings stay where they are.
3. Start PC5. Options › About PC5 shows 1.8.2.

Updating from PC5 1.7.0: it closes at the end of the update instead of restarting, and the console then shows error CE-108255-1. The update is installed all the same: open PC5 again.

### What's new

- **A new look for the library**: the covers are bigger and stand on a floor that mirrors them, the ones beside the chosen game turned a little towards it. The chosen game is framed and lit in its cover's colours, with its name under it and its bits, graphics and size in a pill. The game's background fills the screen behind the covers and shows in the floor too. See [The library](https://github.com/bornaradusin/PC5/wiki/Playing-games#the-library).
- **A backdrop from the cover**: a game without a background gets one made from its cover, blurred to its colours, instead of PC5's dark backdrop. **△ › Appearance › Background › None** gives it the same.
- **Settings › System**: the startup sound, **Keep all logs**, **Picture sources** and the update rows (**Check when PC5 opens**, **Check now**, **Update now**) are together on one page. **In games** keeps vibration, the light bar and the triggers. See [System](https://github.com/bornaradusin/PC5/wiki/Settings#system).
- **More places for covers**: PCGamingWiki (the cover on the game's page) and Wikidata (the Steam game it names, for games Steam's own search doesn't find by that name) join Steam, GOG and Wikipedia. None of them needs an account or a key.
- **Picture sources**: **Settings › System › Picture sources** turns each place PC5 looks for covers and backgrounds on or off. The screens no longer say where a picture came from. See [Picture sources](https://github.com/bornaradusin/PC5/wiki/Settings#picture-sources).
- **Java games**: a game that carries its own Java runtime runs with OpenGL (Mesa Zink), and one made with jpackage runs in one program instead of starting itself again, which the console can't do. Games installed earlier get this the next time they start.
- **Games that start from a batch file**: they run as 32-bit or 64-bit as the program the batch file starts is, whatever an earlier PC5 noted. Games installed earlier get this the next time they start.
- **The startup sound follows the console's volume**: it plays as loud as the controller speaker's volume is set on the console, and not at all at its lowest. PC5's log notes the volume the console gave, for a report if it doesn't follow.
- **Fixes when choosing a cover or background**: a picture that can't be downloaded is passed over for the next one found; **None** stays chosen even with an older picture of your own in the `backgrounds` folder; a cover card that can't be made says so.
- **Uninstall**: an uninstall that can't begin goes back to the game menu's **Uninstall** row.
- Everything in 1.8.1 is unchanged: choosing a cover or background with a search by name, the game menu in groups, DirectX 12 feature level 12_0, spatial audio, the library's folder for FTP, a more detailed log for one game, and the startup sounds.

### Which games run

See the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility), made from players' reports. Got a game running? [Add it](https://github.com/bornaradusin/PC5/discussions/new?category=game-compatibility): the form takes a minute.

### Reporting a problem

Please report problems as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues), not in ProsperoStore's comments, and attach the game's zip from `/data/prospero-win/logs/` (`issue-…zip`, or the game's newest `log-…zip` when nothing crashed). △ on PC5's crash message opens the form for you. Say which PC5 version you use (Options › About PC5) and what happened. Without the log the cause can't be found. If an update from PC5 fails, the message says why; turn on **Settings › System › Keep all logs**, try again and attach PC5's own log.

### Not supported

Games that need a store's launcher or client running (Steam, EA app, Ubisoft Connect, Rockstar Games Launcher), anti-cheat, and games that need kernel drivers. .NET programs that mix .NET and C++ (C++/CLI). Recording or saving video from inside a game. Frame generation for DirectDraw games, games drawn without 3D, and HDR output. Changing a game's controller mode, resolution or aspect ratio while it runs. DRM protected. PC5 installed as a package (`.pkg`) can't update itself: it updates from a folder only.
