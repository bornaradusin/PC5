PC5 2.3.1-programs-test is the first test version that lets a game start other programs. It is everything in 2.3.0, plus the two fixes since then, plus this.

This is a pre-release for testing. PC5 offers it only when **Settings › Check when PC5 opens** is set to **Test versions too**, and it offers you the next normal release when there is one.

### What's new

Some games start a second program while they run: a setup that installs files the game needs (Visual C++, DirectX, .NET, PhysX), or a built-in web browser's own programs, when the game's menus are web pages. A PS5 game can't start another program, so these games stopped early or went on without what they needed.

In this test version, PC5 starts those programs for the game, each as a program of its own, hidden: nothing of them is on the screen, and the game goes on once they're done. PC5 uses elfldr for this, as it already does for its access to `/data`, so keep elfldr loaded.

Nothing changes for games that don't start other programs.

### Install

With **Test versions too** set, PC5 offers this version the next time it opens. By hand: download `PPSA11018-test.zip` below, unzip it and replace the `PPSA11018` folder on the console with the new one, the way you added PC5 (see [Installing and updating](https://github.com/bornaradusin/PC5/wiki/Installing-and-updating#by-hand)). Your games, saves and settings stay. To go back, set the setting to **On**, or do the same with 2.3.0's zip.

### What to test

- A game that stopped at its setup or its launcher, or one whose issue says it couldn't start another program.
- Open a game issue as usual, with **test version** at the start of its title, and attach the game's newest log. **Every log helps, even if the game still doesn't work**: it shows how far the started program got, which is what the next test version needs.
