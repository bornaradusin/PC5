**A test build of PC5 2.1.1 with 120 Hz output and frame generation to 120.** Publish it as a pre-release: PC5's own updater and ProsperoStore don't offer it.

### Install

Download `PPSA11018.zip` below and copy its `PPSA11018` folder over the one you installed PC5 from, as when you added PC5. Your games, saves and settings stay. To go back, install 2.1.1 the same way.

You need a TV or monitor that takes 120 Hz, and the PS5's own **Settings › Screen and Video › Video Output › Enable 120 Hz Output** set to **Automatic**.

### What's new

- **120 Hz output**: **Settings › In games › 120 Hz output** (off by default). On, and with a TV that takes it, games show up to 120 fps instead of 60, and Windows tells them the screen is 120 Hz. Off, or a TV without it, everything stays at 60 Hz as before.
- **Frame generation to 120**: a game's **△ › Graphics › Frame generation** now has three choices, changed with left and right:
  - **Off**.
  - **PC5's** (as before): the game held at half the screen's rate with a frame made between each two. With 120 Hz output on, **60 → 120 fps**; without it, 30 → 60.
  - **MihawkGen**: Mihawk's frame generator, with two frames made between each two of the game's. With 120 Hz output on, **40 → 120 fps**; without it, 30 → 60.

### What to try

- Turn on **120 Hz output**, start a game that already runs well (Half-Life 2, a Source or Unity game) and turn on the overlay's FPS: it should go past 60. The log's `wsi/videoout: presenting at 119.88 Hz` line says the screen took it.
- With 120 Hz on, set **Frame generation** to PC5's (60 → 120) on a game that holds 60, then to **MihawkGen** (40 → 120) on one that holds 40.
- Leave a game both ways (back to PC5, and from a home screen tile) and check the screen comes back normally.
- Turn **120 Hz output** off again and check games are at 60 as before.

Please report what you see, good or bad, as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues/new/choose) with the game's zip from `/data/prospero-win/logs/`: which game, which frame generation, your TV and whether the PS5 showed 120 Hz.

### Known limits

- A game that times itself by the screen's refresh (rare, mostly old or console ports) can run twice as fast at 120 Hz: turn **120 Hz output** off for it.
- Frame generation costs graphics time on every frame: a game that only just reaches 60 (or 40) has no room left for it, and drops to its own rate.
- The overlay's FPS counts the game's own frames with MihawkGen, not the frames made between them; the log has both.
