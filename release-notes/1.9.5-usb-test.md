**A test build: play games from the USB drive without copying them.** Publish it as a pre-release: PC5's own updater and ProsperoStore don't offer it, and it doesn't stand in the way of the next release.

### Install

Download `PPSA11018.zip` below and copy its `PPSA11018` folder over the one you installed PC5 from, as when you added PC5. Your games, saves and settings stay. To go back, install 1.9.5 the same way.

### What to try

1. **Settings › Game maintenance › Install games from USB**, choose a game. The review screen has **△ Play from USB** beside **✕ Install**.
2. **△ Play from USB**: PC5 sets up the game's Windows on the console (saves, settings, shader cache) and copies none of the game's files. The library says **USB** before the game's details.
3. Start the game, with the drive plugged in. With it unplugged, PC5 says to plug it in instead of starting. The drive can be in any USB port.
4. Uninstalling deletes only what is on the console; the game's folder on the drive stays as it is. **△ › Manage › Update** isn't offered: copy the newer version over the folder on the drive.

### What isn't known yet

- Whether the console lets Wine run a game's program and its libraries from the USB drive. If the game doesn't start, its log says why.
- Whether games can write to the drive: some keep their saves or settings in their own folder.
- How much slower loading is from a USB drive, especially a hard drive.

Please report what you find, with the game's log zip from `/data/prospero-win/logs/`: its `PC5 play from usb dir=…` line shows where PC5 found the game.
