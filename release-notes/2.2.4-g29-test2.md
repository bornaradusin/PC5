PC5 2.2.4-g29-test2 is the second test build for the **Logitech G29** steering wheel. It is everything in 2.2.4, plus a **G29 wheel** choice in each game's **Controller** setting: the game then sees a G29 plugged into the PS5 the way a PC sees one plugged in by USB.

This is a pre-release for testing. PC5's own updater doesn't offer it, and it offers you the next normal release when there is one.

### Install

Download `PPSA11018.zip` below, unzip it and replace the `PPSA11018` folder on the console with the new one, the way you added PC5 (see [Installing and updating](https://github.com/bornaradusin/PC5/wiki/Installing-and-updating#by-hand)). Your games, saves and settings stay. To go back, do the same with 2.2.4's zip.

### Setting it up

1. Plug the G29 into the PS5 with its mode switch on **PS4**, before you start the game.
2. Press **△** on the game and set **Controller** to **G29 wheel**.
3. Start the game. Games that support wheels see a **G29 Driving Force Racing Wheel** by Logitech: steering, accelerator, brake and clutch, the D-pad and the buttons. Games with a G29 preset should pick it up as it is.

### What's new since the first test

- The wheel is its own **Controller** choice. With **G29 wheel** the game sees only the wheel, so it can't read it twice. With any other choice the game doesn't see the wheel at all.
- The DualSense still does PC5's own things in **G29 wheel**: hold the touchpad and **OPTIONS** to leave the game, and ✕ and the D-pad answer a game's pop-ups.
- If no wheel is plugged in, a game set to **G29 wheel** gets the DualSense as an Xbox controller, so it can still be played.
- No force feedback yet: the wheel won't push back. That comes next, once we know the wheel is read right.

The buttons are numbered as on a PC: ✕ 1, □ 2, ○ 3, △ 4, right paddle 5, left paddle 6, R2 7, L2 8, Share 9, Options 10, R3 11, L3 12, and the shifter's gears 13 to 19.

### What to test

- Start a racing game with the wheel plugged in and **G29 wheel** chosen. Does the game see the wheel? Do the steering, pedals and buttons do what they should, all the way to each end?
- Please report in the [G29 testers announcement](https://github.com/bornaradusin/PC5/discussions/355): the game, whether it saw the wheel, and what worked or didn't. **Every report helps, even if it all works**: attach the game's newest `log-…zip` from `/data/prospero-win/logs/`. The log shows exactly what the console says about the wheel, which is what the next build needs.
