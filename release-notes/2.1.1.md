PC5 2.1.1 sets up Grand Theft Auto IV for you, brings memory and crash fixes from prospero-win's newest work, adds texture packs for Direct3D 9 games, and two fixes from Mihawk OS.

### Install

- **ProsperoStore**: update PC5 from its page in the store.
- **PC5's own updater**: **Settings › System › Update now**, or **Update now** when PC5 asks as it opens. It downloads only what changed when you have the version before, otherwise the whole app. PC5 restarts by itself when the update is installed.

### What's new

- **Grand Theft Auto IV: The Complete Edition, set up for you**: PC5 starts `GTAIV.exe` with the options the Rockstar Games Launcher would give it, so the game no longer limits its settings to the video memory it finds, starts full screen at the game's **Resolution** and 60 Hz, and plays more smoothly through DXVK. prospero-win measured about 55 fps in the city at 1080p. A `launch.txt` beside `GTAIV.exe` replaces PC5's options (see [Launch options](https://github.com/bornaradusin/PC5/wiki/Launch-options)).

- **Texture packs for Direct3D 9 games**: DXVK can save a game's textures and show your own sharper pictures in their place, set in the game's `env.txt` (see [Launch options](https://github.com/bornaradusin/PC5/wiki/Launch-options#texture-packs-direct3d-9-games)).

### Fixes

- **Stuck at "Closing" after leaving a game**: a game's last frames were still on their way to the screen as PC5 closed it, which could leave the console at its "Closing" screen until a reboot. PC5 now waits for them, leaving to PC5 or to the home screen.
- **OpenGL games slowing to a few fps and crashing after a while**: Wine's own memory now comes from the console's main memory, with room kept for the game, instead of the small pool that ran out.
- **Games that make thousands of threads or fibers ran out of memory**: their stacks now take only what they use, as on Windows, not their whole size at once.
- **Emulators that recompile code ran stale code** (black screen, 0 fps): a page made read-only beside a writable one now faults as on a PC, and accesses beside a protected page stop being slowed down once they come often (Unity games).
- **Black screen with one core busy** in games that draw with Vulkan or OpenGL on the desktop window.
- **Network code that checks a socket option** took it as unset, and a game in a smaller display mode was told its cursor could leave the screen (from Mihawk OS).
- Up-to-date root certificates for games' secure connections, and DXVK 2.6.2-prospero3.

### Which games run

See the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility), made from players' reports and issues. Got a game running? [Add it](https://github.com/bornaradusin/PC5/discussions/new?category=game-compatibility): the form takes a minute.

### Reporting a problem

Please report problems as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues/new/choose), not in ProsperoStore's comments:
- **A game doesn't run** for a game.
- **A problem with PC5** for PC5 itself.

Attach the game's zip from `/data/prospero-win/logs/`: an `issue-…zip`, or the game's newest `log-…zip` when nothing crashed. The form asks for it, as the cause can't be found without it. **△** on PC5's crash message, or a game's **△ › Manage › Report a problem**, opens the form for you, filled in.

If an update from PC5 fails, the message says why. Turn on **Settings › System › Keep all logs**, try again and attach PC5's own log. See [Logs and debugging](https://github.com/bornaradusin/PC5/wiki/Logs-and-debugging) for what an issue may ask for.

### Not supported

- Games that need a store's launcher or client running (Steam, EA app, Ubisoft Connect, Rockstar Games Launcher).
- Anti-cheat, games that need kernel drivers, and DRM-protected games.
- .NET programs that mix .NET and C++ (C++/CLI).
- 16-bit Windows and DOS programs.
- Recording or saving video from inside a game.
- Frame generation for DirectDraw games and games drawn without 3D, and HDR output.
- Changing a game's controller mode, resolution or aspect ratio while it runs.
- Updating a PC5 installed as a package (`.pkg`): it updates from a folder only.
