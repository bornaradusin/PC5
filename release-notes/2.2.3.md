PC5 2.2.3 tidies a game's Appearance into one place for its pictures, lets you pick each game's loading picture from the console or your phone, makes PC5's web page dark all through, gives Graphics memory more sizes, and brings surround sound and the smoother start from 2.2.2-test.

### Install

- **ProsperoStore**: update PC5 from its page in the store.
- **PC5's own updater**: **Settings › System › Update now**, or **Update now** when PC5 asks as it opens. It downloads only what changed when you have the version before, otherwise the whole app. PC5 restarts by itself when the update is installed.

### What's new

- **Media settings and backup**: a game's **△ › Appearance** now opens with **Media settings and backup**, which holds its **Cover**, **Background**, **Loading screen** and **Music, video and backup**. Then come **Library music**, **Home screen tile** and **Tile picture**.
- **A loading picture for each game**: **Appearance › Media settings and backup › Loading screen** takes a JPEG or PNG from a USB drive or the console (**Choose image file**), the game's own background (**Use its background**), or one from your phone (**□**). **Use PC5's** goes back to the built-in one. The phone's library appearance page has **Loading screen** too.
- **Surround sound**: press **△** on a game and set **Sound output** to **5.1** or **7.1** for a surround system. The game is told it has that many speakers, and each sound plays on its own speaker. **Stereo** stays the default.
- **A smoother start**: on Play, PC5 fades to black, and the loading screen fades in as soon as the game can draw, until its first picture. No more loading picture, black, then loading picture again.
- **More Graphics memory sizes**: a game's **△ › Graphics › Graphics memory** now goes from less to more. A 64-bit game has **2 GB**, **3 GB**, **Auto (4 GB)**, **5 GB**, **6 GB** and **Maximum**; a 32-bit one **512 MB**, **1 GB**, **Auto (2 GB)**, **3 GB** and **Maximum**. A smaller size leaves more of the console's shared memory for the game itself, for a game that crashes from running out of memory.
- **The web page in dark mode**: PC5's web page is dark whatever your phone's or browser's theme, like PC5 and its phone pages.

### Fixes from your reports

- **Closed at once since 2.2.2, in some games using AMD's library**: a game that looks for AMD's GPU library without shipping its own copy asked PC5's stand-in for its version over and over until it crashed. It now goes on without it, as on a PC without AMD's library.
- **A .NET game stopping with "System.IO.IOException" as it starts**: a game that sets its console window's title first thing (one that runs without a window on the console) now starts.
- **No text in some Unity games' menus**: PC5 now puts a free stand-in for Arial (Liberation Sans, with the same letter sizes) in each game's `C:\Windows\Fonts`, where some Unity games look for it by name. A real Arial you added yourself stays.

### Which games run

See the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility), made from players' reports and issues. Got a game running? [Add it](https://github.com/bornaradusin/PC5/discussions/new?category=game-compatibility): the form takes a minute.

### Reporting a problem

Please report problems as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues/new/choose), not in ProsperoStore's comments:
- **A game doesn't run** for a game.
- **A problem with PC5** for PC5 itself.

Attach the game's zip from `/data/prospero-win/logs/`: an `issue-…zip`, or the game's newest `log-…zip` when nothing crashed. The form asks for it, as the cause can't be found without it. **△** on PC5's crash message, or a game's **△ › Manage › Report a problem**, opens the form for you, filled in.

If an update from PC5 fails, the message says why. Turn on **Settings › System › Keep all logs**, try again and attach PC5's own log. See [Logs and debugging](https://github.com/bornaradusin/PC5/wiki/Logs-and-debugging) for what an issue may ask for.

### Not supported

- Games that need a store's launcher or client running (Steam, EA app, Ubisoft Connect, Rockstar Games Launcher).
- Anti-cheat, games that need kernel drivers, and DRM-protected games.
- .NET programs that mix .NET and C++ (C++/CLI).
- 16-bit Windows and DOS programs.
- Recording or saving video from inside a game.
- Frame generation for DirectDraw games and games drawn without 3D, and HDR output.
