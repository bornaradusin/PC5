Games that start their own settings tool, a game's pointer across a smaller display mode, Xbox controllers for games that look for them, Java games that list the network, Unreal Engine 5 games on Direct3D 12 that ask for a shared resource, and the crash kept in a long log. Issues now go through a form, which Report on GitHub fills in.

### Install

- **ProsperoStore**: update PC5 from its page in the store.
- **PC5's own updater**: **Settings › System › Update now**, or **Update now** when PC5 asks as it opens. PC5 restarts by itself when the update is installed.

### What's new

- **Games that start their own settings tool**: a game that starts its settings tool each time it opens, and waits for it, was taken for a launcher starting its game. It closed, and the settings tool, which shows itself only the first time, closed at once. A program named as a settings tool is left alone now, and the game goes on.
- **A game's pointer across a smaller display mode**: a game that follows the system's pointer in a display mode smaller than the screen (1024 × 768, for example) could reach only about five sixths of its width. PC5 took the game's picture to start at the screen's left edge, where Wine centres it. The pointer now stops at the edges of the picture as it is shown.
- **Xbox controllers for games that look for them**: a game that tells Xbox controllers from other joysticks by Windows' list of devices didn't find PC5's controller in it, took it for a joystick it doesn't play with, and never read it as an Xbox controller. Each controller is in that list now, as Windows lists an Xbox 360 controller, and plays in **Xbox controller** mode.
- **Java games that list the network**: the console runs no network service for Windows programs, so every request for the network interfaces failed, and a Java game whose random numbers start from them stopped (as it began a new game, for one). PC5 answers now with the loopback interface Windows always has.
- **Unreal Engine 5 games on Direct3D 12 that ask for a shared resource**: a game that made a Direct3D 12 resource to share with another graphics device closed as it started, as the console's graphics driver can't share one. The resource is made as an ordinary one now, and the game carries on.
- **The crash kept in a long log**: a game whose own crash handler, or a more detailed log, went on writing long after a crash pushed the crash out of the log PC5 kept. The part with the first crash is kept now too, as `…-crash.log` in the game's zip.
- **Change program offers every program** in the game's folder, its tools and installers last, so a game's own settings tool named like an installer can be chosen there.
- **Issues through a form**: GitHub's form for a game that doesn't run asks for the game, PC5's version, the firmware, what goes wrong, what happened and the log, and **Report on GitHub** opens it with the game, its program, PC5's version, the firmware and what PC5 saw filled in. The [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility) lists each game with an issue: being looked at while the issue is open, then working perfectly once it is fixed, or not running.
- **PC5's home screen background** (from 1.8.7) not showing? Delete PC5 from the home screen (**Options › Delete**), then reload ShadowMountPlus: it installs PC5 again with the background. See [The home screen background](https://github.com/bornaradusin/PC5/wiki/Installing-and-updating#the-home-screen-background).
- Everything in 1.8.7 is unchanged: the new icon and home screen background, **Options › Game maintenance**, a game started by its own launcher running as itself, and all since 1.8.2.

### Which games run

See the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility), made from players' reports and issues. Got a game running? [Add it](https://github.com/bornaradusin/PC5/discussions/new?category=game-compatibility): the form takes a minute.

### Reporting a problem

Please report problems as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues/new/choose), not in ProsperoStore's comments: **A game doesn't run** for a game, **A problem with PC5** for PC5 itself. Attach the game's zip from `/data/prospero-win/logs/` (`issue-…zip`, or the game's newest `log-…zip` when nothing crashed): the form asks for it, as the cause can't be found without it. △ on PC5's crash message opens the form for you, filled in. If an update from PC5 fails, the message says why; turn on **Settings › System › Keep all logs**, try again and attach PC5's own log. See [Logs and debugging](https://github.com/bornaradusin/PC5/wiki/Logs-and-debugging) for what an issue may ask for.

### Not supported

Games that need a store's launcher or client running (Steam, EA app, Ubisoft Connect, Rockstar Games Launcher), anti-cheat, and games that need kernel drivers. .NET programs that mix .NET and C++ (C++/CLI). 16-bit Windows and DOS programs. Recording or saving video from inside a game. Frame generation for DirectDraw games, games drawn without 3D, and HDR output. Changing a game's controller mode, resolution or aspect ratio while it runs. DRM protected. PC5 installed as a package (`.pkg`) can't update itself: it updates from a folder only.
