PC5 2.4.1 lets 32-bit games use more memory, keeps games that hold many files open from running out of them, fixes peer-to-peer networking, and shows the pointer where it really is at the screen's edges.

### Install

- **ProsperoStore**: update PC5 from its page in the store.
- **PC5's own updater**: **Settings › System › Update now**, or **Update now** when PC5 asks as it opens. It downloads only what changed when you have the version before, otherwise the whole app. PC5 restarts by itself when the update is installed.

### Fixed

- Some 32-bit games that load a lot ran out of memory at the start and closed. A 32-bit game had 4 GB to use, but only the first 2 GB were kept for it, so the console could take the rest and the game was told about room it couldn't have. The whole 4 GB is now kept for it, and a game is only told about room it can use.
- A game asking for memory the console no longer has got an error it took for a bug, and some closed at once. It now gets the out-of-memory error Windows gives, which games can handle.
- Games that hold many files open at once (big mod setups, games with a database per world, games that watch many folders for changes) closed with "Too many open files". The console allows a game few open files, and PC5 already put away files a game only reads until they're needed again. It now does the same for files a game writes to, files it locks and files it reads in the background, and it can watch many more folders.
- Older 32-bit games built with the Watcom compiler stopped with an illegal instruction about a second after starting, as the console couldn't run one of their ways of putting a value on the stack.
- Games using peer-to-peer networking failed while setting up their connections: the console reports some network details in its own way, refuses one setting Windows allows, and the list of network adapters failed without DNS settings. All three now work as on Windows.
- Near the bottom or right edge of the screen, the pointer drawn on screen stopped while the real pointer moved on, so a click could land beside the button you pointed at. The pointer now shows where it really is.
- A window that repainted under a dialog could draw over the dialog, and the part of a window uncovered when another window closed or moved stayed black. Windows now keep their order on the screen and repaint what's uncovered.

### Changed

- When a game runs out of memory or open files, its log now says what used them up, so the cause can be found from a report.

### Which games run

See the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility), made from players' reports and issues. Got a game running? Use **Report it works** (a game's **△ › Manage**, or PC5's web page), or [add it here](https://github.com/bornaradusin/PC5/discussions/new?category=game-compatibility): the form takes a minute.

### Reporting a problem

Please report problems as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues/new/choose), not in ProsperoStore's comments:
- **A game doesn't run** for a game.
- **A problem with PC5** for PC5 itself.

Attach the game's zip from `/data/prospero-win/logs/`: an `issue-…zip`, or the game's newest `log-…zip` when nothing crashed. The form asks for it, as the cause can't be found without it. **△** on PC5's crash message, or a game's **△ › Manage › Report a problem**, opens the form for you, filled in.

If an update from PC5 fails, the message says why. Turn on **Settings › System › Keep all logs**, try again and attach PC5's own log. See [Logs and debugging](https://github.com/bornaradusin/PC5/wiki/Logs-and-debugging) for what an issue may ask for.

### Not supported

- Games that need a store's launcher or client running (Steam, EA app, Ubisoft Connect, Rockstar Games Launcher).
- Anti-cheat, games that need kernel drivers, and DRM-protected games.
- .NET programs that mix .NET and C++ (C++/CLI).
- 16-bit Windows and DOS programs.
- Recording or saving video from inside a game.
- Frame generation for DirectDraw games and games drawn without 3D, and HDR output.
