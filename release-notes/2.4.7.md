PC5 2.4.7 reads Microsoft's DirectX End-User Runtime as it is downloaded, gives older games Microsoft's own sound engine where Wine's falls short, and fixes games that stopped for memory while enough was free.

### Install

- **ProsperoStore**: update PC5 from its page in the store.
- **PC5's own updater**: **Settings › System › Update now**, or **Update now** when PC5 asks as it opens. It downloads only what changed when you have the version before, otherwise the whole app. PC5 restarts by itself when the update is installed.

### New

- **Microsoft's DirectX End-User Runtime, as it is downloaded**: put Microsoft's `directx_Jun2010_redist.exe` in `/data/prospero-win/pc5/dx9`. At the next game start PC5 takes Microsoft's Direct3D helpers (D3DX) and shader compilers from it for every game, as DLLs put in that folder already did, and Microsoft's sound engine for older games (XACT) for the games whose sound needs Microsoft's own. It reads the package once. A game that needs it and doesn't have it says so in its log.

### Fixed

- **Older games whose voices went missing**, with their ambient sound too loud and out of step: a game that hands the sound engine for older games (XACT) its own audio engine gets Microsoft's XACT from the DirectX End-User Runtime above, as Wine's doesn't take it.
- **Games whose screen stayed black after switching to fullscreen** (Direct3D 9): their effects (D3DX) answered "not implemented" when the game reset its graphics for fullscreen, and the game stopped drawing. They now answer as Microsoft's do.
- **Games that stopped with "out of memory" while enough memory was free**: the console's memory was split into pieces, and a game's large request, or a large graphics buffer, needed one piece bigger than any free. Such a request now takes several pieces.
- **"Video memory has been exhausted" shown by Unreal Engine games**: the console's graphics driver counted every graphics allocation twice in the memory it reports.
- **A game drawn only with DirectX 12 taken for DirectX 11** (RE Engine), as its protected program shows only DXGI: it was given Wine's own DirectX 12, which couldn't make its device. It starts with DirectX 12, an installed one too.
- **A game's log when memory runs out** now tells all the memory still free, beside the largest free piece, so a full console can be told from one whose memory is split into pieces.

### Which games run

See the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility), made from players' reports and issues. Got a game running? Use **Report it works** (a game's **△ › Manage**, or PC5's web page), or [add it here](https://github.com/bornaradusin/PC5/discussions/new?category=game-compatibility): the form takes a minute.

### Reporting a problem

Please report problems as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues/new/choose), not in ProsperoStore's comments:
- **A game doesn't run** for a game.
- **A problem with PC5** for PC5 itself.

Attach the game's zip from `/data/prospero-win/logs/`: an `issue-…zip`, or the game's newest `log-…zip` when nothing crashed. The form asks for it, as the cause can't be found without it. **△** on PC5's crash message, or a game's **△ › Manage › Report a problem**, opens the form for you, filled in.

If an update from PC5 fails, the message says why. Turn on **Settings › System › Keep all logs**, try again and attach PC5's own log. See [Logs and debugging](https://github.com/bornaradusin/PC5/wiki/Logs-and-debugging) for what an issue may ask for.

### Not supported

- Games that need a store's launcher or client running (Steam, EA app, Ubisoft Connect, Rockstar Games Launcher).
- Anti-cheat, games that need kernel drivers, and DRM-protected games.
- .NET programs that mix .NET and C++ (C++/CLI).
- 16-bit Windows and DOS programs.
- Recording or saving video from inside a game.
- Frame generation for DirectDraw games and games drawn without 3D, and HDR output.
