PC5 2.3.8 gets more Steam copies going, keeps the DLC a copy lists, opens a game's menu faster on a USB hard drive, and fixes a crash as some games' movies start.

### Install

- **ProsperoStore**: update PC5 from its page in the store.
- **PC5's own updater**: **Settings › System › Update now**, or **Update now** when PC5 asks as it opens. It downloads only what changed when you have the version before, otherwise the whole app. PC5 restarts by itself when the update is installed.

### Fixed

- **Copies with ColdClientLoader**: a folder ColdClientLoader runs from now always gets PC5's Steam emulator, even when another stand-in's files are in it too. Such a game asked for the Steam app before.
- **DLC**: when a copy lists its DLC for its own Steam stand-in, PC5's Steam emulator now keeps that list, so the DLC show as owned instead of "buy".
- **A game's menu on a USB hard drive**: the first time a game's menu opened, PC5 looked at every one of its files to find Steam's library, which took seconds for a game with many files on a hard drive. It now looks only at what it needs.
- **Movies without a frame rate**: a movie whose file gives no frame rate (WMV movies) was reported as 0 frames a second, and a game could crash as it started. It now gets the rate the video itself has.

### Which games run

See the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility), made from players' reports and issues. Got a game running? Use **Report it works** (a game's **△ › Manage**, or PC5's web page), or [add it here](https://github.com/bornaradusin/PC5/discussions/new?category=game-compatibility): the form takes a minute.

### Reporting a problem

Please report problems as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues/new/choose), not in ProsperoStore's comments:
- **A game doesn't run** for a game.
- **A problem with PC5** for PC5 itself.

Attach the game's zip from `/data/prospero-win/logs/`: an `issue-…zip`, or the game's newest `log-…zip` when nothing crashed. The form asks for it, as the cause can't be found without it. **△** on PC5's crash message, or a game's **△ › Manage › Report a problem**, opens the form for you, filled in.

If an update from PC5 fails, the message says why. Turn on **Settings › System › Keep all logs**, try again and attach PC5's own log. See [Logs and debugging](https://github.com/bornaradusin/PC5/wiki/Logs-and-debugging) for what an issue may ask for.

### Not supported

- Games that need a store's launcher or client running (Steam, EA app, Ubisoft Connect, Rockstar Games Launcher).
- Anti-cheat, games that need kernel drivers, and DRM-protected games.
- .NET programs that mix .NET and C++ (C++/CLI).
- 16-bit Windows and DOS programs.
- Recording or saving video from inside a game.
- Frame generation for DirectDraw games and games drawn without 3D, and HDR output.
