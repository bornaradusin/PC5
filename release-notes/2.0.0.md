PC5 2.0.0 adds a file manager, home screen tiles that are apps of their own, playing a game straight from its USB drive, and an INSTALL folder for games sent over FTP. It also has fixes from your reports.

### Install

- **ProsperoStore**: update PC5 from its page in the store.
- **PC5's own updater**: **Settings › System › Update now**, or **Update now** when PC5 asks as it opens. It downloads only what changed when you have the version before, otherwise the whole app. PC5 restarts by itself when the update is installed.

### What's new

- **File manager**:
  - **△ › Manage › Game files** opens a game's own folder.
  - **Settings › File manager** opens the console's drives: Console storage, USB drives and Extended storage.
  - You can **Copy**, **Cut**, **Paste** (Skip, Keep both or Replace), **Rename**, make a **New folder** and **Delete**. Tick several items with **□**.
  - Use it to add mods, swap a game's files or copy saves, all without FTP. See [File manager](https://github.com/bornaradusin/PC5/wiki/File-manager).
- **Home screen tiles that are apps of their own**:
  - **△ › Appearance › Home screen tile** now makes a small app, a few MB in size. It starts its game straight away, without PC5's screens.
  - The tile runs from PC5's folder, and PC5 keeps every tile up to date when it updates.
  - **△ › Appearance › Tile picture** picks a square picture for the tile, from SteamGridDB with your key in `api_keys.txt`. The tile's background follows the game's.
  - Close PC5 so ShadowMountPlus can add the tile.
  - To leave a game started from its tile, quit it from the PS button's menu. Touchpad + Options doesn't close a tile.
  - A tile made by an earlier PC5 stays as it was: turn it off and on again to make the new kind. Thanks to SuperLeiyan for this.
- **Play from USB**:
  - In **Install games from USB**, choosing a game shows its review screen. Press **△ Play from USB** there instead of Install.
  - Nothing of the game is copied: PC5 makes only the game's Windows on the console, and the game plays from its drive, in whichever USB port it is in. The drive needs to stay plugged in.
  - It is useful for big games, or to try a game before installing it.
- **INSTALL folder**:
  - PC5's folder now has an **INSTALL** folder. Put a game's folder there, over FTP or with the file manager, and PC5 asks to install it the next time it opens.
  - Installing moves the game into PC5's library instead of copying it, so it takes a moment and no extra room. From another drive it is copied, then deleted from INSTALL.
  - If an install from there is stopped or cut short, the game goes back to INSTALL.
- **Reporting a problem with a newer PC5 out**: **Report on GitHub** first offers the newer PC5, as the problem may already be fixed in it. You can choose **Update now** or report anyway.

### Fixes from your reports

- **Video memory**: **△ › Graphics › Video memory** is **Auto** by default. A 32-bit game is told it has 2 GB of video memory, as some older games misread more and refused to start or ran their system check wrong. **Full** gives the game all of it.
- **Direct3D 12 detection**: Unreal Engine 5 games that ship Direct3D 12's Agility SDK now draw with Direct3D 12.
- **Missing folders**: when a game makes a folder in its user folders whose parent isn't there (normally made by the game's installer), the parent is now made too. Games that stopped with an error as they started now carry on.
- **A crash at the start**: older games that set a processor flag no longer crash as they start.
- **A game's own environment**: an `env.txt` in a game's `pc5` folder sets environment variables for that game, for fixes a game's community documents. See [Launch options](https://github.com/bornaradusin/PC5/wiki/Launch-options).
- **Better crash reports**:
  - When a game stops with an uncaught C++ error, the log names it, with its message.
  - A crash logs the code at the fault.
  - A game's start logs which graphics it draws with.
- Everything else in 1.9.8 is unchanged.

### Which games run

See the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility), made from players' reports and issues. Got a game running? [Add it](https://github.com/bornaradusin/PC5/discussions/new?category=game-compatibility): the form takes a minute.

### Reporting a problem

Please report problems as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues/new/choose), not in ProsperoStore's comments:
- **A game doesn't run** for a game.
- **A problem with PC5** for PC5 itself.

Attach the game's zip from `/data/prospero-win/logs/`: an `issue-…zip`, or the game's newest `log-…zip` when nothing crashed. The form asks for it, as the cause can't be found without it. **△** on PC5's crash message opens the form for you, filled in.

If an update from PC5 fails, the message says why. Turn on **Settings › System › Keep all logs**, try again and attach PC5's own log. See [Logs and debugging](https://github.com/bornaradusin/PC5/wiki/Logs-and-debugging) for what an issue may ask for.

### Not supported

- Games that need a store's launcher or client running (Steam, EA app, Ubisoft Connect, Rockstar Games Launcher).
- Anti-cheat, games that need kernel drivers, and DRM-protected games.
- .NET programs that mix .NET and C++ (C++/CLI).
- 16-bit Windows and DOS programs.
- Recording or saving video from inside a game.
- Frame generation for DirectDraw games and games drawn without 3D, and HDR output.
- Changing a game's controller mode, resolution or aspect ratio while it runs.
- Updating a PC5 installed as a package (`.pkg`): it updates from a folder only.
