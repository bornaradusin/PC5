**A test build of PC5 2.0.3.** Publish it as a pre-release: PC5's own updater and ProsperoStore don't offer it.

### Install

Download `PPSA11018.zip` below and copy its `PPSA11018` folder over the one you installed PC5 from, as when you added PC5. Your games, saves and settings stay. To go back, install 2.0.2 the same way.

### What's new

- **Settings › Network**: the FTP server moved here from Game maintenance. You can now set a **Username** and an optional **Password** for it. With none set, any login works, as before.
- **Web page**: in **Settings › Network**, turn on **Web page** and open the address it shows in a browser on your phone or PC. From there you can:
  - send a game's folder to PC5 (it then asks to install it);
  - edit a game's launch options (`launch.txt`, `env.txt`);
  - download a game's newest log and the kept logs.

  It asks for the same username and password as the FTP server.
- **Games made for Steam**: a game whose copy needs Steam's `steam_api64.dll` gets an emulator in its place (gbe_fork), so it starts without Steam's client. **△ › Manage › Steam emulator** turns it off for a game. Programs wrapped in Steam's DRM (SteamStub) still don't start; PC5 now says why instead of crashing.
- **PhysX and other redistributables**: the first time a game starts, PC5 installs the MSI packages it carries (`_CommonRedist`, `Redist`, `PhysX` folders), such as NVIDIA's PhysX, once.
- **Faster loading**: small reads come from a bigger piece of the file read ahead, and opening a file costs fewer steps. Games with many small files should load faster.

### Fixes

- **Godot games** on OpenGL open their window ("Failed to create an OpenGL window").
- **Older games that crashed reading `FFFFFFFF`** at start: the instructions the console refuses (SGDT, SIDT and others an anti-tamper or CPU check runs) now work.
- **32-bit games** whose memory landed above 4 GB.
- **A controller turned off and on again** is seen again by the game.
- **A game that crashes** now closes instead of freezing.
- **Source engine games** no longer hang at start.
- **Direct3D 9 effects** that games build from their source, and a Direct3D 9 reset onto a new window.
- **.NET games with large folders** ("Too many open files"), and listing a game's subfolders.

### What isn't known yet

- Whether PhysX packages from real games install the way they should.
- How fast a large game sends over the web page.

Please report what works and what doesn't as an [issue](https://github.com/bornaradusin/PC5/issues/new/choose), with the game's zip from `/data/prospero-win/logs/`.
