Update a game without losing its saves, keep a game's saves when you uninstall it, each game's background behind the library, a choice of startup sounds, smoother movies, and PC5 restarts by itself after an update.

### Install

From PC5 1.7.0: **Settings › Updates › Update now**, or **Update now** when PC5 asks as it opens.

By hand:

1. Download `PPSA11018.zip` and unzip it.
2. Replace the `PPSA11018` folder on the console with the new one, the way you add homebrew. Your games, saves and settings stay where they are.
3. Start PC5. Options › About PC5 shows 1.8.0.

PC5 1.7.0 closes at the end of the update instead of restarting, and the console then shows error CE-108255-1. The update is installed all the same: open PC5 again. From 1.8.0 on, PC5 restarts by itself.

### What's new

- **Update a game**: put the newer version's folder on the USB drive, choose the game, press △ and choose **Update**. The files the newer version has replace the game's, the others stay, and the game's saves, settings, options, cover and home screen tile stay as they were. PC5 copies the folder and checks the copy before it changes anything, so a stopped or failed update leaves the game as it was. See [Updating a game](https://github.com/bornaradusin/PC5/wiki/Installing-games#updating-a-game).
- **Keep saves when uninstalling**: uninstalling a game now offers **Keep saves** (the game goes, its saves, settings and options stay) or **Delete all**. Install the same game again and PC5 asks to put its saves back. Kept saves are listed in **Options › Uninstall game**, after the games, to delete them. See [Keeping a game's saves](https://github.com/bornaradusin/PC5/wiki/Installing-games#keeping-a-games-saves).
- **Game backgrounds**: while a game is chosen in the library, its background fills the screen behind the covers, darkened so the covers and text stay easy to read, and fades to the next game's as you move.
  - PC5 finds them by itself while the library shows, for every game, games installed with an earlier PC5 included: the background of the cover chosen when the game was installed, or Steam's library background or GOG's background of the best match.
  - Your own: put `background.jpg` or `background.png` at the top of the game's folder on the USB drive before installing, or, for a game already installed, a picture in `/data/prospero-win/backgrounds/` named after the game (its folder name, its name in PC5 or its id), as for your own covers. See [Backgrounds](https://github.com/bornaradusin/PC5/wiki/Covers#backgrounds).
  - A game no source has a background for keeps PC5's own backdrop.
- **Startup sounds to choose from**: **Settings › In games › Startup sound** chooses the sound PC5 plays on the controller when it opens, or **Off**: PC5, Beeper - Push, Cha-Ching, cheap chinese speaker, fahh, funny message tone, rizz and System Activated. Choosing a sound plays it. Add your own as `.wav` files in `/data/prospero-win/sounds/`: mono or stereo, any sample rate. See [Startup sound](https://github.com/bornaradusin/PC5/wiki/Settings#startup-sound).
- **Restart after an update**: when an update is installed, **Restart PC5** starts the new version straight away, with no error from the console.
- **Movies**: movies no longer stutter, skip or drift ahead of their sound, and movies a game draws through Direct3D 9 into Direct3D 11 show instead of staying black.
- **Sound**: fixed a crash in XAudio2's mixer that made some games close a few seconds to minutes into play.
- **Controller**: in Xbox controller mode, pressing the touchpad is Back (it was Guide), so a game's Back menu no longer needs Create, which also opens the console's share menu. Create stays Back.
- Thanks to @SuperLeiyan for the movie, sound and controller fixes.
- Everything in 1.7.0 is unchanged: PC5 updates itself from GitHub, DirectDraw games in 3D, games that start from a `.bat` file, up to four players, DirectInput controllers, choosing a game's program, Report on GitHub, and one zip per log.

### Which games run

See the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility), made from players' reports. Got a game running? [Add it](https://github.com/bornaradusin/PC5/discussions/new?category=game-compatibility): the form takes a minute.

### Reporting a problem

Please report problems as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues), not in ProsperoStore's comments, and attach the game's zip from `/data/prospero-win/logs/` (`issue-…zip`, or the game's newest `log-…zip` when nothing crashed). △ on PC5's crash message opens the form for you. Say which PC5 version you use (Options › About PC5) and what happened. Without the log the cause can't be found. If an update from PC5 fails, the message says why; turn on **Settings › Keep all logs**, try again and attach PC5's own log.

### Not supported

Games that need a store's launcher or client running (Steam, EA app, Ubisoft Connect, Rockstar Games Launcher), anti-cheat, and games that need kernel drivers. .NET programs that mix .NET and C++ (C++/CLI). Recording or saving video from inside a game. Frame generation for DirectDraw games, games drawn without 3D, and HDR output. Changing a game's controller mode, resolution or aspect ratio while it runs. DRM protected. PC5 installed as a package (`.pkg`) can't update itself: it updates from a folder only.
