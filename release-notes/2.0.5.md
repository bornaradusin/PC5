PC5 2.0.5 brings a new look, each game's details on Home, and fixes from your reports.

### Install

- **ProsperoStore**: update PC5 from its page in the store.
- **PC5's own updater**: **Settings › System › Update now**, or **Update now** when PC5 asks as it opens. It downloads only what changed when you have the version before, otherwise the whole app. PC5 restarts by itself when the update is installed.

### What's new

- **A new look**: **Home** shows the chosen game over its own background, with its genres, its logo, a line about it, **Play Game** and its settings, and the covers in a row below. **L1** / **R1** move between the tabs: **Home**, **Library**, **Install** and **Settings**.
- **Library**: every game in a grid, with filters for **All**, **Recently played**, **Favourites**, **USB drive** and **Needs attention**. **L2** / **R2** change the filter.
- **Favourites**: **□** marks a game as a favourite, with a star on its cover.
- **Focus mode**: **R3** hides everything but the game's picture.
- **Each game's details**: PC5 finds a game's store page once and keeps its genres, description and logo for Home. It recognises a game by its Steam or GOG files and keeps what it found, so its cover, background and details are the right ones; if it picked the wrong game, set the Steam app ID on the web page.
- **A boot screen** as PC5 opens.
- A game without a background shows PC5's own picture, and a game without a cover shows PC5's cover with its name on it.

### Fixes from your reports

- **"Needs Steam" for copies that don't**: a copy of a game with Steam's DRM taken off, which runs on a PC without Steam, was refused because its program still had the DRM's empty section. Only a program that really starts in Steam's DRM is refused now.
- **"Failed to allocate memory" while loading a level**: a game that takes its memory in many small pieces, as Unreal Engine 5 games do, ran out of room to keep track of them at about 4.5 GB, with most of the console's memory still free. There is room for all of it now.
- **Games closing as they start because of their crash reporter**: a game that starts its crash reporter as it opens was taken for a launcher handing over to another program, and closed. The crash reporter is left out now and the game goes on.
- **Missing menus or maps in .NET games on a USB drive**: a folder opened a second way, when the first didn't work, was refused as an invalid path. It opens now.
- **Shader errors in older Direct3D 9 games**: the shaders PC5 compiles for a game wrote numbers in a form the game couldn't read back, and shaders for the oldest shader model failed. Both work now.

### Which games run

See the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility), made from players' reports and issues. Got a game running? [Add it](https://github.com/bornaradusin/PC5/discussions/new?category=game-compatibility): the form takes a minute.

### Reporting a problem

Please report problems as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues/new/choose), not in ProsperoStore's comments:
- **A game doesn't run** for a game.
- **A problem with PC5** for PC5 itself.

Attach the game's zip from `/data/prospero-win/logs/`: an `issue-…zip`, or the game's newest `log-…zip` when nothing crashed. The form asks for it, as the cause can't be found without it. **△** on PC5's crash message, or a game's **△ › Manage › Report a problem**, opens the form for you, filled in.

If an update from PC5 fails, the message says why. Turn on **Settings › System › Keep all logs**, try again and attach PC5's own log. See [Logs and debugging](https://github.com/bornaradusin/PC5/wiki/Logs-and-debugging) for what an issue may ask for.

### Not supported

- Games that need a store's launcher or client running (Steam, EA app, Ubisoft Connect, Rockstar Games Launcher).
- Anti-cheat, games that need kernel drivers, and DRM-protected games.
- .NET programs that mix .NET and C++ (C++/CLI).
- 16-bit Windows and DOS programs.
- Recording or saving video from inside a game.
- Frame generation for DirectDraw games and games drawn without 3D, and HDR output.
- Changing a game's controller mode, resolution or aspect ratio while it runs.
- Updating a PC5 installed as a package (`.pkg`): it updates from a folder only.
