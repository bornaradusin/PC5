PC5 2.1.2 brings 120 Hz output with frame generation up to 120 fps, lets you change a game's text files on the console and from the web page, a new loading screen, and keeps the last games in view on Home.

### Install

- **ProsperoStore**: update PC5 from its page in the store.
- **PC5's own updater**: **Settings › System › Update now**, or **Update now** when PC5 asks as it opens. It downloads only what changed when you have the version before, otherwise the whole app. PC5 restarts by itself when the update is installed.

### What's new

- **120 Hz output**: **Settings › In games › 120 Hz output** (off by default). On, with a TV or monitor that takes 120 Hz and the PS5's own **Settings › Screen and Video › Video Output › Enable 120 Hz Output** set to **Automatic**, games show up to 120 fps instead of 60, and Windows tells them the screen is 120 Hz. Off, or with a TV without it, everything stays at 60 Hz as before.

- **Frame generation up to 120 fps**: with 120 Hz output on, a game's **△ › Graphics › Frame generation** has three choices, changed with left and right:
  - **Off**.
  - **60 → 120 fps**: the game held at 60 with a frame made between each two (PC5's frame generation, as before).
  - **40 → 120 fps**: the game held at 40 with two frames made between each two, for a game that can't hold 60 (MihawkGen, from Mihawk OS).

  With 120 Hz output off it's **Off** or **30 → 60 fps** as before; a game set to 40 → 120 uses 30 → 60 until 120 Hz output is on again.

- **Change a game's text files** ([#263](https://github.com/bornaradusin/PC5/discussions/263)):
  - **On the console**: in the **File manager** (or a game's **△ › Manage › Game files**), **✕** on a text file (`.ini`, `.cfg`, `.txt` and the like) opens it as lines. **✕** changes a line with the PS5's keyboard; **△** adds a line below or above, deletes one, or saves. Back asks before leaving changes unsaved. In a read-only place the file is only shown.
  - **On the web page**: each game's **Files** opens its folder, or its **Windows** (the registry's `.reg` files, and `drive_c` with saves and settings), and a text file in a box with your computer's or phone's keyboard.
  - Both save the file as it was: the same encoding (UTF-8, UTF-16 or the older one-byte-a-letter kind) and the same line ends, so Windows games read it as before. Change `.reg` files only when no game is running.

- **A new loading screen**: a gaming PC glowing blue, **LAUNCHING GAME** and a bar filling while the game starts, in place of the falling green code and the game's name.

- **Home keeps the last games in view**: going right to the end of the row, the last three covers stay on screen and the choice moves along them, instead of the earlier games sliding away until only the last one is left.

### Fixes

- PC5's own on-screen keyboard (a search, a name, a line of a file) now takes up to about 1000 characters instead of 95.

### Which games run

See the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility), made from players' reports and issues. Got a game running? [Add it](https://github.com/bornaradusin/PC5/discussions/new?category=game-compatibility): the form takes a minute.

### Reporting a problem

Please report problems as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues/new/choose), not in ProsperoStore's comments:
- **A game doesn't run** for a game.
- **A problem with PC5** for PC5 itself.

Attach the game's zip from `/data/prospero-win/logs/`: an `issue-…zip`, or the game's newest `log-…zip` when nothing crashed. The form asks for it, as the cause can't be found without it. **△** on PC5's crash message, or a game's **△ › Manage › Report a problem**, opens the form for you, filled in.

If an update from PC5 fails, the message says why. Turn on **Settings › System › Keep all logs**, try again and attach PC5's own log. See [Logs and debugging](https://github.com/bornaradusin/PC5/wiki/Logs-and-debugging) for what an issue may ask for.

### Not supported

- Games that need a store's launcher or client running (Steam, EA app, Ubisoft Connect, Rockstar Games Launcher).
- Anti-cheat, games that need kernel drivers, and DRM-protected games.
- .NET programs that mix .NET and C++ (C++/CLI).
- 16-bit Windows and DOS programs.
- Recording or saving video from inside a game.
- Frame generation for DirectDraw games and games drawn without 3D, and HDR output.
- Output above 120 Hz, and variable refresh rate (VRR).
- Changing a game's controller mode, resolution or aspect ratio while it runs.
- Updating a PC5 installed as a package (`.pkg`): it updates from a folder only.
