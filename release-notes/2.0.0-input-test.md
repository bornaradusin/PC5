**A test build: the mouse wheel, and a button that slows the pointer.** It is 2.0.0 with these two added. Publish it as a pre-release: PC5's own updater and ProsperoStore don't offer it.

### Install

Download `PPSA11018.zip` below and copy its `PPSA11018` folder over the one you installed PC5 from, as when you added PC5. Your games, saves and settings stay. To go back, install 2.0.0 the same way.

### What to try

- **A USB mouse's wheel** now reaches the game, as on a PC. Before, it did nothing.
- **The wheel from the controller**: with a game on **Keyboard & mouse**, open **△ › Button mapping**, choose a button and pick **Wheel up** or **Wheel down** (after the mouse buttons in the key list). Each press turns the wheel one notch. In a Ren'Py visual novel, Wheel up steps back through the dialogue and Wheel down forward again.
- **Slow pointer button**: in **Button mapping**, with a stick moving the pointer, **Slow pointer button** picks a button (none by default). While you hold it, the pointer moves slower, for placing and aiming precisely. **Slower by** sets by how much, 10 % to 90 % (50 % by default). That button does only this while it is chosen.

### What isn't known yet

- Whether a USB mouse's wheel turns the right way round. Please say if it scrolls the wrong way.

Please report what you find on the discussion it came from, or as an issue with the game's zip from `/data/prospero-win/logs/`.
