PC5 2.3.0 offers **settings that worked for others** from the game compatibility list, says what likely went wrong when a game closes, and fixes Unreal Engine games that asked to install Visual C++ and old OpenGL games that closed before showing anything.

### Install

- **ProsperoStore**: update PC5 from its page in the store.
- **PC5's own updater**: **Settings › System › Update now**, or **Update now** when PC5 asks as it opens. It downloads only what changed when you have the version before, otherwise the whole app. PC5 restarts by itself when the update is installed.

### New

- **Settings that worked for others**: when a player has reported a game working (**Report it works**) with settings different from yours, the game's **△ › Graphics** has **Settings that worked**. It shows what they changed (Graphics mode, Controller, Frame generation, Game memory, Stutter fix, Steam emulator, Sound output) and its launch options, and uses them for you; your other settings stay. PC5 also asks once when you first press **Play**. **Report it works** now includes the game's launch options too.
- **What likely went wrong**: when a game closes, PC5's message now says why when its log shows it: an installer it tried to start (which can't run on the console), files in the copy that aren't the game's as its store ships it, OpenGL that never started, or what the game's own crash report says. The same goes in the report's **What PC5 saw** and the log's about.txt.
- **Test versions**: **Settings › System › Check when PC5 opens** has a third choice, **Test versions too**: PC5 then also offers test versions, fixes to try before everyone gets them. They may have new problems; set it back to **On** to get only releases.
- **A copy with another program's files**: when a game's folder has files that aren't the game's as its store ships it (OnlineFix, steam_api_o.dll), **Install** says so before you install it, as games with them often close before starting.
- **More in the logs** for reports: keys still held when a game closes, quick button taps, system files a game looked for and didn't find, and the console's free memory once a minute.
- **Issues**: the form asks where your copy is from.

### Fixes from your reports

- **Unreal Engine games that asked for Visual C++ 2015-2022**: a game started from the small starter program in its top folder (the one named like the game, beside its Engine folder) asked to install Visual C++ and then closed, as its installer can't run on the console. PC5 already has Visual C++ 2015-2022, so it now starts the game's own program in the starter's place, as the starter would after its check.
- **Old OpenGL games that asked for 16-bit colour** got no OpenGL at all and closed before showing anything. They now get the closest 32-bit colour, as a PC's graphics driver gives them.

### Which games run

See the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility), made from players' reports and issues. Got a game running? Use **Report it works** (a game's **△ › Manage**, or PC5's web page), or [add it here](https://github.com/bornaradusin/PC5/discussions/new?category=game-compatibility): the form takes a minute.

### Reporting a problem

Please report problems as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues/new/choose), not in ProsperoStore's comments:
- **A game doesn't run** for a game.
- **A problem with PC5** for PC5 itself.

Attach the game's zip from `/data/prospero-win/logs/`: an `issue-…zip`, or the game's newest `log-…zip` when nothing crashed. The form asks for it, as the cause can't be found without it. **△** on PC5's crash message, or a game's **△ › Manage › Report a problem**, opens the form for you, filled in.

If an update from PC5 fails, the message says why. Turn on **Settings › System › Keep all logs**, try again and attach PC5's own log. See [Logs and debugging](https://github.com/bornaradusin/PC5/wiki/Logs-and-debugging) for what an issue may ask for.

### Not supported

- Games that need a store's launcher or client running (Steam, EA app, Ubisoft Connect, Rockstar Games Launcher).
- Anti-cheat, games that need kernel drivers, and DRM-protected games.
- .NET programs that mix .NET and C++ (C++/CLI).
- 16-bit Windows and DOS programs.
- Recording or saving video from inside a game.
- Frame generation for DirectDraw games and games drawn without 3D, and HDR output.
