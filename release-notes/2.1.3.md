PC5 2.1.3 lets Pro Evolution Soccer 6 start without its installer, on the console or a USB drive.

### Install

- **ProsperoStore**: update PC5 from its page in the store.
- **PC5's own updater**: **Settings › System › Update now**, or **Update now** when PC5 asks as it opens. It downloads only what changed when you have the version before, otherwise the whole app. PC5 restarts by itself when the update is installed.

### What's new

- **Pro Evolution Soccer 6 starts** (and its `settings.exe` opens) instead of saying "The game is not properly installed." The game looks for the registry keys its installer writes on Windows, which a copied folder doesn't have. PC5 now adds them once, before it starts: its folder and the languages it has. It works for a game installed on the console, on a USB drive or on extended storage, and no CD key is written. Thanks to [youss17x](https://github.com/youss17x) for this ([#285](https://github.com/bornaradusin/PC5/pull/285)). Other games with the same check can be added the same way: please open an issue with the game's log.

### Game compatibility list

- A game now has one row: the best result anyone has had with it, with its other reports and issues beside it. A game that runs for one player can run, given the right copy or version.
- Games that run anti-cheat (Easy Anti-Cheat, BattlEye or their own) have a row of their own, **Anti-cheat: can't run**: anti-cheat needs Windows' own kernel, which the PS5 doesn't have.

### Which games run

See the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility), made from players' reports and issues. Got a game running? [Add it](https://github.com/bornaradusin/PC5/discussions/new?category=game-compatibility): the form takes a minute.

### Reporting a problem

Please report problems as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues/new/choose), not in ProsperoStore's comments:
- **A game doesn't run** for a game.
- **A problem with PC5** for PC5 itself.

Attach the game's zip from `/data/prospero-win/logs/`: an `issue-…zip`, or the game's newest `log-…zip` when nothing crashed. The form asks for it, as the cause can't be found without it. **△** on PC5's crash message, or a game's **△ › Manage › Report a problem**, opens the form for you, filled in.

If an update from PC5 fails, the message says why. Turn on **Settings › System › Keep all logs**, try again and attach PC5's own log. See [Logs and debugging](https://github.com/bornaradusin/PC5/wiki/Logs-and-debugging) for what an issue may ask for.

### Not supported

- Games that need a store's launcher or client running (Steam, EA app, Ubisoft Connect, Rockstar Games Launcher).
- Anti-cheat, games that need kernel drivers, and DRM-protected games.
- .NET programs that mix .NET and C++ (C++/CLI).
- 16-bit Windows and DOS programs.
- Recording or saving video from inside a game.
- Frame generation for DirectDraw games and games drawn without 3D, and HDR output.
- Output above 120 Hz, and variable refresh rate (VRR).
- Changing a game's controller mode, resolution or aspect ratio while it runs.
- Updating a PC5 installed as a package (`.pkg`): it updates from a folder only.
