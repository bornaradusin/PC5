Updates from PC5 that download only the files that changed: from 1.9.0 to the next version on, PC5's own updater usually downloads a small part of the app where it downloaded the whole of it.

### Install

- **ProsperoStore**: update PC5 from its page in the store.
- **PC5's own updater**: **Settings › System › Update now**, or **Update now** when PC5 asks as it opens. PC5 restarts by itself when the update is installed. This update to 1.9.0 still downloads the whole app (PC5 1.8.8 doesn't know the smaller download yet); the next ones download only what changed.

### What's new

- **Updates that download only what changed**: each release now has, beside the whole app (`PPSA11018.zip`), an update zip (`PPSA11018-update.zip`) with only the files that differ from the release before it, and the app carries the list of its files with their checksums (`pc5/manifest.txt`). PC5's updater downloads the update zip when every other file of the new release is on the console as it was released, and checks each file against the lists. When it can't use it (you skipped a version, or a file of PC5's was changed), it says why in its log and downloads the whole app as before. "PC5 x.y.z is available" gives the size it will download.
- **The same build gives the same files**: the times, random IDs and the build machine's name that the build wrote into PC5's empty Windows (its registry and DLLs) are fixed values now, so a new version changes only the files it really changes, and the update zip stays small.
- "PC5 x.y.z is available" says **Later: Settings › System**, where **Update now** is, not the old Settings › Updates.
- Everything in 1.8.8 is unchanged: settings tools, the pointer across a smaller display mode, Xbox controllers for games that look for them, Java games that list the network, shared Direct3D 12 resources, the crash kept in a long log, and all since 1.8.2.

### Which games run

See the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility), made from players' reports and issues. Got a game running? [Add it](https://github.com/bornaradusin/PC5/discussions/new?category=game-compatibility): the form takes a minute.

### Reporting a problem

Please report problems as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues/new/choose), not in ProsperoStore's comments: **A game doesn't run** for a game, **A problem with PC5** for PC5 itself. Attach the game's zip from `/data/prospero-win/logs/` (`issue-…zip`, or the game's newest `log-…zip` when nothing crashed): the form asks for it, as the cause can't be found without it. △ on PC5's crash message opens the form for you, filled in. If an update from PC5 fails, the message says why; turn on **Settings › System › Keep all logs**, try again and attach PC5's own log. See [Logs and debugging](https://github.com/bornaradusin/PC5/wiki/Logs-and-debugging) for what an issue may ask for.

### Not supported

Games that need a store's launcher or client running (Steam, EA app, Ubisoft Connect, Rockstar Games Launcher), anti-cheat, and games that need kernel drivers. .NET programs that mix .NET and C++ (C++/CLI). 16-bit Windows and DOS programs. Recording or saving video from inside a game. Frame generation for DirectDraw games, games drawn without 3D, and HDR output. Changing a game's controller mode, resolution or aspect ratio while it runs. DRM protected. PC5 installed as a package (`.pkg`) can't update itself: it updates from a folder only.
