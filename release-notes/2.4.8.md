PC5 2.4.8 fixes Electron games that stopped after an earlier start ended early, DirectDraw games that stopped drawing at their menu, and lets a static recompilation of an Xbox 360 game have its memory where it wants it.

### Install

- **ProsperoStore**: update PC5 from its page in the store.
- **PC5's own updater**: **Settings › System › Update now**, or **Update now** when PC5 asks as it opens. It downloads only what changed when you have the version before, otherwise the whole app. PC5 restarts by itself when the update is installed.

### New

- **Memory for a program that wants it at addresses of its own**: a static recompilation of an Xbox 360 game (GTAV's gtav-recomp) puts its memory at fixed addresses, which the console and Wine already used. `WINE_PS5_HIGH_FREE_GIB=8` in the game's **Environment variables (env.txt)** keeps them free for it. Other games don't need it. See [Launch options](https://github.com/bornaradusin/PC5/wiki/Launch-options).

### Fixed

- **Electron games that stopped after an earlier start ended early** (Riverfront Rumble, Noreya): that start left the game's browser caches, or a settings file, cut short, and each later start stopped on them ("Unable to map Index file", "Unexpected end of JSON input"). Before a game starts, such caches are now cleared, for the game to make again, and an empty `.json` is moved aside as `.json.pc5-empty`.
- **DirectDraw games whose picture stopped at their menu while their sound went on** (Arcanum): a click on the desktop around the game's window made it give up its screen, and it waited to be switched back to. The console has nothing to switch to, so the game keeps its screen.
- **Infinity Engine games still unable to find their data** (Icewind Dale II): a tab or other invisible character after a path in the game's ini is no longer taken as part of it, and the game's log says why a path was left as it was.
- **.NET games that need Managed DirectX** (Ceville) are told so when they stop, with where it is on a Windows PC, instead of only closing.
- **Large .NET programs** whose loader gave up looking for their .NET version get a config naming it.
- **A game's log** now names the caller when a game crashes through an empty function pointer, a crash its own crash handler kept from the log, and, for a Unity game with the Xbox controller setting, what the game asks of the controller. Its picture counts say they don't count a Direct3D or OpenGL game's own pictures, and a refused memory reservation in an empty range is named as one.
- **Unity games that saw no Xbox controller** (Yestersol): a game that asks to be told of controllers without naming a window is now told of the console's controller, as on Windows.

### Which games run

See the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility), made from players' reports and issues. Got a game running? Use **Report it works** (a game's **△ › Manage**, or PC5's web page), or [add it here](https://github.com/bornaradusin/PC5/discussions/new?category=game-compatibility): the form takes a minute.

### Reporting a problem

Please report problems as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues/new/choose), not in ProsperoStore's comments:
- **A game doesn't run** for a game.
- **A problem with PC5** for PC5 itself.

Attach the game's zip from `/data/prospero-win/logs/`: an `issue-…zip`, or the game's newest `log-…zip` when nothing crashed. The form asks for it, as the cause can't be found without it. **△** on PC5's crash message, or a game's **△ › Manage › Report a problem**, opens the form for you, filled in.

If an update from PC5 fails, the message says why. Turn on **Settings › System › Keep all logs**, try again and attach PC5's own log. See [Logs and debugging](https://github.com/bornaradusin/PC5/wiki/Logs-and-debugging) for what an issue may ask for.

### Not supported

- Games that need a store's launcher or client running (Steam, EA app, Ubisoft Connect, Rockstar Games Launcher).
- Anti-cheat, games that need kernel drivers, and DRM-protected games.
- .NET programs that mix .NET and C++ (C++/CLI).
- 16-bit Windows and DOS programs.
- Recording or saving video from inside a game.
- Frame generation for DirectDraw games and games drawn without 3D, and HDR output.
